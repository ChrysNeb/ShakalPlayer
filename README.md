# ShakalEQ для Android

Офлайн-плеер с пресетами деградации звука. Открой аудиофайл или запусти встроенное 12-секундное демо, выбери пресет и меняй степень шакализации на ходу. Кнопка «Звук» переключает между оригиналом и пресетом с сохранением выбранной степени.

| Пресет | Обработка |
| --- | --- |
| Наушники из самолёта | Моно, узкая полоса, резонанс средней частоты |
| Пожёванная кассета | Плавающая задержка для детонации, шипение, провалы каналов |
| Винил, убитый в хлам | Ослабление верхних частот, гул, случайные щелчки и царапина раз в 1,8 секунды |
| Уши с Ali за $0.20 | Резонанс на верхней середине, срез баса, баланс влево |
| TWS с Ali за $1 | Бубнящий бас, квантование, ступеньки ресемплинга, имитация провалов связи по каналам |
| Домофон у подъезда | Моно, 50 Гц, узкая полоса и сильная сатурация |
| MP3 из аськи | Срез верхов, ступенчатый ресемплинг и 6-битное квантование |

Android 8.0 и выше. Пресеты обрабатывают файлы, открытые в ShakalEQ. Поддерживаемые кодеки зависят от Android-устройства. Вход — моно или стерео, выход — стерео PCM16 на системный аудиовыход. При уходе приложения с экрана воспроизведение ставится на паузу. Доступ к интернету и микрофону приложению не нужен.

## Скачать APK

[ShakalEQ 0.1.0 для Android](https://github.com/ChrysNeb/ShakalEQ/releases/tag/v0.1.0) · Android 8.0+

## Сборка

Открой эту папку в Android Studio или запусти `gradlew.bat assembleDebug` на Windows (`./gradlew assembleDebug` на Linux/macOS). Нужны JDK 17 и Android SDK 35. APK находится в `app/build/outputs/apk/debug/`.

Демо уже включено в исходники. Для генерации заново запусти `node tools/make-demo.mjs`.

## Проверка DSP

Запусти `javac -d build/dsp-check app/src/main/java/space/shakalizator/eq/ShakalDsp.java tools/DspCheck.java`, затем `java -cp build/dsp-check space.shakalizator.eq.DspCheck`.
